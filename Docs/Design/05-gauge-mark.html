RevUp Gauge Mark

A rev-counter needle inside a rounded badge, built the same way as the EncontrolE4 reference set: one flat background, a light dial, one accent element that carries the swap between variants.

Motif
Tachometer sweep: a 270° dial with a needle pointing into the redline. Reads as "rev up" at any size, ties directly to the car-meet subject without spelling out a literal car.

Small

Two shapes carry the whole read at 20–32px: the open ring and the angled needle. No detail is lost because none of the detail depends on fine line work.

Large

At badge size the gap in the dial, the needle's taper, and the hub give it real depth instead of sitting flat, the same way the reference mark layers a leaf, a check and a plus.

Variation

Only the needle or the background ever changes. Ring, hub and geometry stay fixed, so new contexts (alerts, light placements) are a one-line recolor, not a redraw.
